## 1.1 复审后的 Web-only 决策

2026-06-26 复审结论：

- Product Design A/B/C 三张图的视觉完成度和方向更符合当前判断，应作为本阶段主视觉真相。
- 三张图不再作为并列首页方案，而是固定映射为：A 用于首页，B 用于 Run 工作区，C 的根因联动用于 Attention。
- 当前阶段聚焦 Web 工作台交互，不做 APP 页面兼容模式。
- 移动端、窄屏、APP 适配后续如需要再单独开设计任务。
- Pencil 继续只作为对象语义、任务闭环和审核安全边界校验，不参与视觉主导。

## 2. 融合原则

```text
Product Design A/B/C 主导最终界面视觉、布局和交互体验
+ Pencil 六页原型校验流程完整性、对象语义、状态归属和审核安全边界
+ 本阶段只验证 Web 工作台交互，不验证 APP/移动端布局
```

Product Design 不再只是参考图，下一步原型以它作为主体验方向；Pencil 不作为最终视觉
主方案，只作为结构与安全边界校验底稿。

## 5. 验收重点

- 首页、Run、Attention 分别保持 A/B/C 三张图的既有风格，不再混合成单一视觉样式。
- 桌面端 Run 工作区能呈现 B1 的三栏结构和底部事件抽屉。
- Web 工作台原型在桌面视口下保持 A/B/C 的视觉方向和信息层级。
- Attention 中一个根因只对应一个主 Attention Item。
- 审核动作不覆盖历史，只表达创建新 Artifact version 和 NodeAttempt 的规则。
- 所有状态必须带对象归属，避免只显示无主语状态。

## 6. 暂不覆盖

- 完整后端、真实 Workflow Runner、真实 API 调用。
- Workflow Builder、Infinite Canvas、Agent Center 和资源库完整交互。
- APP/移动端兼容模式和窄屏响应式方案。
- 完整无障碍公告、键盘流和真实焦点管理。
