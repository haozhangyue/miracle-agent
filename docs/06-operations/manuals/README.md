## 内容真相规则

1. `help-manifest.json` 负责文章发现、角色分类、顺序和图片白名单，不复制正文。
2. 61-65 是角色和公共手册真相，Web 帮助中心读取这些 Markdown。
3. `VERSION_HISTORY.md` 记录技术和项目演进，65 只记录用户可感知变化。
4. 对象模型和 API 的精确协议仍以 `docs/02-architecture`、`docs/04-engineering` 和当前代码为准。
5. 当前角色只是阅读视角，不代表 Miracle 已经实现账号、RBAC 或多租户权限。

## 更新责任

| 变化 | 需要同步的资料 |
|---|---|
| 菜单、按钮、操作路径 | 使用者手册、必要截图、用户版本变化 |
| 启动、端口、凭证、目录 | 管理员手册、故障排查、用户版本变化 |
| Schema、API、Adapter、扩展方式 | 开发维护手册、关联技术文档、版本历史 |
| 新错误或恢复动作 | 故障排查，必要时同步使用者或管理员手册 |
| 纯内部重构 | 版本历史；提交说明注明“无手册影响” |

发布前必须验证：Manifest 可解析、文章与图片存在、Markdown 链接有效、Web 帮助可打开、
截图不包含凭证、个人路径、未脱敏正文或隐藏推理。
