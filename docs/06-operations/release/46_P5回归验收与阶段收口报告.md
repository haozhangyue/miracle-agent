### 4.2 回归中发现并修复的问题

Sidecar roadmap API 测试把 `current_node_id` 硬编码为旧值 `p4-06`。任务基线进入 P5 后，
实际 API 正确返回 P5 当前任务，但测试错误失败。

修复方式：

- 不再断言某个历史阶段 ID。
- 改为验证 `current_node_id` 对应的任务真实存在且 `status = current`。
- 继续验证总体阶段存在 current 项、D10 历史任务和 Git/evidence 同步状态。

该修复让 roadmap 测试验证长期不变量，后续阶段推进不再需要同步修改硬编码任务 ID。
